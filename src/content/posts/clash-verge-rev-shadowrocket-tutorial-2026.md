## 一、Windows / macOS：Clash Verge Rev 核心设置四步法

从 **[客户端导航（/compass/）](/compass/)** 下载安装好最新版 Clash Verge Rev 后，按顺序检查以下四项设置：

### 1. 导入机场通用订阅链接
- 登录你购买的支持第三方订阅的机场后台（例如 **[光速云](/brands/#guangsuyun)**、**[微风网络](/brands/#weifeng)**、**[星岛梦](/brands/#xingdaomeng)**、**[二猫云](/brands/#ermao)**、**[一翻云](/brands/#yifan)**）。
- 复制 **Clash 订阅链接**（或通用订阅链接）。
- 打开 Clash Verge Rev -> 左侧点击 **「订阅 (Profiles)」** -> 顶部粘贴链接并点击 **「导入 (Import)」** -> 单击下方生成的配置卡片使其高亮生效。

### 2. 区分「系统代理 (System Proxy)」与「TUN 虚拟网卡模式」
在左侧 **「设置 (Settings)」** 面板里，有两个最关键的开关：
- **系统代理 (System Proxy)**：日常最常用的模式。开启后，Chrome、Edge 浏览器以及遵循系统代理的软件会自动走代理分流。
- **TUN (虚拟网卡) 模式**：当你发现 **桌面版应用（如 Discord、Telegram、游戏客户端、Cursor 编辑器、Git 命令行）** 不理会系统代理时，点击开启 **「TUN 模式」**（首次开启需在设置旁点击「安装服务 / 授权内核权限」）。TUN 模式会在系统底层接管所有网卡流量，彻底解决应用不走代理的问题。

### 3. 开启「规则 (Rule)」模式，切勿长开「全局 (Global)」
在左侧 **「代理 (Proxies)」** 顶部，有三个模式切换按钮：
- **规则 (Rule)（强烈推荐）**：国内网站（淘宝、B站、微信、网银）直接走本地宽带秒开，不消耗机场流量；只有海外网站与 AI 工具才走专线节点。
- **全局 (Global)**：所有国内国外流量强行绕道海外节点，不仅看国内视频变慢，还会飞速浪费你的套餐流量，仅在排查特殊故障时临时使用。

## 二、iOS / iPadOS：Shadowrocket（小火箭）最佳配置姿势

1. **一键导入或扫码添加订阅**：
   - 在机场后台直接点击「一键导入 Shadowrocket」，或复制通用订阅链接 -> 打开小火箭点击左上角 `+` 号 -> 类型选 `Subscribe` -> 粘贴 URL 保存。
2. **全局路由务必要选「配置 (Config)」**：
   - 回到小火箭首页，点击中间的 **「全局路由 (Global Routing)」**，确保勾选的是 **「配置 (Config)」**（对应桌面端的规则分流模式），而不是 `代理 (Proxy)`。
3. **开启「订阅自动后台更新」**：
   - 进入右下角 **「设置 -> 订阅」**，勾选 **「打开时更新」**。这样当机场主更换了入口 IP 或新增了专线节点时，你打开 App 就会自动同步最新列表。

## 三、排错急救箱：节点全部 Timeout 超时或更新订阅失败怎么办？

如果你导入订阅后发现所有节点都显示红色 `Timeout`（超时），95% 是以下三个原因之一：

1. **电脑系统时间误差超过 30 秒（最常见！）**：
   - VLESS、Trojan、VMess 等现代协议对客户端与服务器的时间戳校验极其严格。如果 Windows 或手机系统时间快了或慢了哪怕 1 分钟，握手就会直接被服务端拒绝。
   - **修复方法**：打开系统「日期和时间设置」-> 点击 **「立即同步 (Sync now)」**，确保开启自动设置时间，然后重新测速即可恢复全绿。
2. **同时开了两个代理软件或浏览器插件冲突**：
   - 检查电脑右下角是否同时挂着旧版 v2rayN、加速器或 Chrome 里的 SwitchyOmega 插件，关闭多余代理软件并重启 Clash Verge Rev。
3. **订阅域名在当前本地宽带下被 DNS 污染**：
   - 如果点击「更新订阅」报错，可先在客户端设置中开启 `使用系统代理更新订阅`，或前往机场官网后台复制备用订阅地址（若你觉得维护订阅太繁琐，也可以搭配一家免配置的专属客户端机场如 **[飞猫云](/brands/#feimao)** 或 **[无忧链接](/brands/#wuyou)** 作为保底）。
