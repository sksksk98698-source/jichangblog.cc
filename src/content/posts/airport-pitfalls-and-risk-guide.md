## 一、线路架构拆解：直连、公网中转、IPLC 与 IEPL 到底差在哪？

### 1. 公网直连（Direct）
本地电脑直接连海外机房。由于数据全程裸奔经过国际出口防火墙（GFW），不仅晚高峰丢包严重，而且一到敏感时期 IP 极易被封禁。目前除了极少数自建 VPS 玩家，主流商业机场已很少采用纯直连。

### 2. BGP 公网中转（Relay）
国内用户先连到国内的 BGP 入口服务器（如广州、深圳、上海移动/电信/联通入口），再由国内服务器通过公网跨境转发到香港、日本、新加坡落地机房。
- **优点**：带宽成本比内网专线低，日常非敏感期速度很快（如 **[飞猫云](/brands/#feimao)**、**[灵猫网络](/brands/#lingmao)**、**[暮光加速](/brands/#muguang)** 的部分智能调度线路）。
- **缺点**：出境段依然经过公网审查节点，特殊时期偶有波动，依赖机场主切换入口的速度。

### 3. IPLC 与 IEPL 内网专线（Dedicated Line）
这是目前中高端稳定机场（如 **[光速云](/brands/#guangsuyun)**、**[微风网络](/brands/#weifeng)**、**[星岛梦](/brands/#xingdaomeng)**、**[二猫云](/brands/#ermao)**、**[唯兔云](/brands/#weitu)**、**[Firefly](/brands/#firefly)**、**[一翻云](/brands/#yifan)**）的核心底座。
- **共同核心**：国内入口（如深港、沪日、京德）与海外出口之间走的是运营商级内网物理/以太网专线，**流量不过公网 GFW 墙**，因此不受特殊时期封锁干扰，且跨海延迟极低（深港段通常仅 2ms–5ms）。
- **IPLC 与 IEPL 的工程差异**：
  - **IPLC（International Private Leased Circuit）**：传统点对点物理租赁专线，位于物理层/数据链路层底端，隔离性高，但开通周期长、单 Mbps 租金昂贵。
  - **IEPL（International Ethernet Private Line）**：基于以太网/MPLS 技术的二层国际专线，在保持内网不过墙、低抖动的同时，支持更灵活的带宽弹性扩容与多点互联，因此成为 2024–2026 年主力专线机场最广泛采用的架构。

**一句话避坑**：写着「IEPL / IPLC」不代表晚高峰一定不卡——因为专线带宽很贵，如果一家机场把年付压到二三十块钱还号称「全线 IPLC 不限速」，大概率是极其严重的超售（几千人挤几十兆专线入口）或者是假专线真公网。

## 二、传输协议怎么选：Shadowsocks、Trojan、VLESS 与 Hysteria 2

在 **[42家机场品牌全库](/brands/)** 中，不同品牌的协议倾向差异明显：

1. **VLESS（含 VLESS-Reality）**：
   - **现状**：2026 年专线机场的头号主力协议（**[光速云](/brands/#guangsuyun)**、**[微风网络](/brands/#weifeng)**、**[二猫云](/brands/#ermao)**、**[无忧链接](/brands/#wuyou)**、**[Firefly](/brands/#firefly)**、**[SOGO云](/brands/#sogo)**、**[速界](/brands/#sujie)** 均采用）。
   - **优势**：去掉了冗余的二次加密开销，在 IEPL/IPLC 内网专线环境下握手延迟极低、吞吐上限高（在本站 **[光速云 9Gbps 实测](/posts/guangsuyun-review-2026/)** 与 **[无忧链接 50 节点实测](/posts/wuyou-feimao-weifeng-muguang-review/)** 中单节点均轻松跑过 460 MB/s）。
2. **Trojan**：
   - **现状**：**[星岛梦](/brands/#xingdaomeng)**、**[唯兔云](/brands/#weitu)**、**[全球云](/brands/#quanqiu)** 等采用。
   - **优势**：将代理流量伪装成标准 HTTPS 网站访问，成熟度高，对各类老版本客户端兼容性好。
3. **Hysteria 2（歇斯底里 2）**：
   - **现状**：**[一翻云](/brands/#yifan)** 等多协议机场提供。
   - **优势**：基于改进版 QUIC (UDP) 协议，专为高丢包、劣质宽带环境设计，能用暴力发包抢占带宽；但在部分对 UDP 限速严厉的校园网或移动宽带下可能触发 QoS，适合与 VLESS 搭配互补。
4. **Shadowsocks (SS)**：
   - **现状**：**[一翻云](/brands/#yifan)**、**[全球云](/brands/#quanqiu)** 及部分老牌 IPLC 机场（如历史档案中的飞鸟、龙猫云、青云梯）使用。
   - **优势**：在内网专线（流量不过墙）的前提下，SS 加密最轻量，对软路由 CPU 占用极低；但如果是公网直连或普通中转，裸 SS 极易被识别封锁。

## 三、识别「同源站群（换壳机场）」与防跑路 5 条铁律

很多新手以为自己买了 A 机场当主力、B 机场当备用，结果某天上游一拔线，两家同时失联——因为它们本来就是同一个团队开的「同源站群」。

结合本站整理的 42 家档案，给你 5 条真金白银的防坑建议：

1. **主备机场一定要错开「同源站群」与「客户端形态」**：
   - 例如，**[大佬云](/brands/#dalaoyun)**、**[闪电鼠](/brands/#shandianshu)**、**[云界线](/brands/#yunjiexian)**、**[榴莲云](/brands/#liulianyun)**、**[环球梯](/brands/#huanqiuti)** 均属于 `qwerty.*` 5.6 元档体系，不要同时买其中两家互为备用。
   - 最科学的搭配是：**1 家老牌支持通用订阅的 IEPL 主力（如 [#1 光速云](/brands/#guangsuyun) 或 [#6 星岛梦](/brands/#xingdaomeng)） + 1 家不同体系的免配置小包或一次性永久包（如 [#3 飞猫云](/brands/#feimao) 或 [#8 无忧链接](/brands/#wuyou)）**。
2. **新成立不到 1 年的机场，坚决「先月付、后年付」**：
   - 2025–2026 年上线的新品牌（即便当期测速高达几百 MB/s），长期运维能力仍需时间检验。花 18–25 元买一个月实测晚高峰 20:00–23:00 的表现，永远比贪图 7 折直接锁死一年更安全。
3. **善用「一次性永久不限时流量包」当备用仓**：
   - 如果你只是为了防止主力机场偶尔维护时失联，没必要同时交两份月租。像 **[光速云（¥147/247GB）](/brands/#guangsuyun)**、**[二猫云（¥99/100GB）](/brands/#ermao)**、**[星岛梦（¥100/100GB）](/brands/#xingdaomeng)**、**[一翻云（¥100/100GB）](/brands/#yifan)** 都提供不过期的一次性流量包，平时不用不扣流量，关键时刻能救命。
4. **看清「AI 解锁」与「退款政策」的真实边界**：
   - 任何承诺「100% 节点永久秒开 ChatGPT/Claude」的宣传都是吹牛——因为 OpenAI 和 Anthropic 的风控规则每周都在变。像 **[光速云](/brands/#guangsuyun)**、**[速界](/brands/#sujie)**、**[可信云](/brands/#kexin)** 这样坦诚告知「视节点而定、需配合切换节点」的品牌反而更值得信赖。
5. **只从正版渠道下载客户端**：
   - 无论用哪家机场，客户端一律从 **[本站全平台客户端导航（/compass/）](/compass/)** 指向的 GitHub 官方仓库或 App Store 下载，绝不安装来历不明的修改版软件。
