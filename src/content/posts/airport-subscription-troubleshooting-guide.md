## 故障一：关掉电脑或退出 Clash 后，国内百度、B站、微信网页版全部打不开了！

**原因分析**：
这是 Windows 用户最常遇到的「代理残留假死」。当你在未正常关闭「系统代理 (System Proxy)」的情况下直接强制关机或杀掉客户端进程，Windows 注册表里的代理服务器地址依然指向本地 `127.0.0.1:7897`（而此时代理软件已经没在运行了），导致所有流量撞墙。

**两步秒修方案**：
1. **方法 A**：重新打开你的 **[Clash Verge Rev 或 v2rayN](/compass/)**，先打开「系统代理」再手动关掉它，然后正常退出软件。
2. **方法 B（系统设置直接清除）**：按 `Win + I` 打开 Windows 设置 -> **网络和 Internet** -> **代理 (Proxy)** -> 找到「使用代理服务器」，将其开关拨到 **「关闭 (Off)」** 并点击保存，国内网络立刻恢复。

## 故障二：复制了机场订阅链接，导入客户端却报错「Network Error / 0 个节点」

**原因分析与排查顺序**：
1. **检查是否下错了停更旧版客户端（占 60%）**：
   - 如果你还在用 `Clash for Windows (0.20.x)` 或旧版 `Clash for Android`，它们无法识别 **[光速云](/brands/#guangsuyun)**、**[微风网络](/brands/#weifeng)**、**[二猫云](/brands/#ermao)**、**[一翻云](/brands/#yifan)** 的 **VLESS** 与 **Hysteria 2** 节点，导入后就会变成空列表。请立刻去 **[客户端导航（/compass/）](/compass/)** 更换为 **Clash Verge Rev** 或 **FlClash**。
2. **检查是否把「官网注册链接」当成了「订阅链接」**：
   - 订阅链接是从机场后台「一键订阅 -> 复制通用/Clash订阅」拿到的专属 API 链接，切勿直接把浏览器地址栏网址填进去。
3. **本地宽带（尤其是移动/校园网）对订阅域名进行了 DNS 抢答污染**：
   - 在客户端设置中将 DNS 修改为 `223.5.5.5` 或 `119.29.29.29`，或者登录机场官网后台切换「备用订阅地址」重新导入。

## 故障三：前几天用得好好的，今天突然所有节点测速全红 `Timeout`

**三步排查法**：
1. **第一步（90% 命中）：同步系统时间！**
   - 检查电脑或手机右下角时间是否慢了或快了超过 30 秒。进入系统时间设置点击 **「立即同步时间」**，再点测速往往瞬间全绿。
2. **第二步：刷新/更新一次订阅（Update Profile）**
   - 专线机场为了保障高可用，每隔一段时间会例行切换中转入口 IP 或调整端口。在客户端「订阅」页面点击刷新按钮拉取最新节点配置即可。
3. **第三步：检查套餐流量是否耗尽或到期**
   - 登录机场官网面板查看剩余流量。为避免主力机场突发维护时手忙脚乱，建议平时在客户端里多导入一家 **[百元永久不限时备用流量包（如光速云 147 套餐或星岛梦 100G 包）](/posts/unlimited-time-traffic-pack-airports-2026/)**。

## 故障四：开了代理能上 YouTube，但打开 ChatGPT / Claude 显示 Access Denied

**原因与解决方法**：
1. **节点选在了香港（HK）**：OpenAI 与 Anthropic 不支持香港 IP 直连。请切到 **日本、新加坡、台湾、美国或欧洲节点**（详见 **[《2026 AI 办公专线机场推荐与防封指南》](/posts/ai-tools-chatgpt-claude-airports-2026/)**）。
2. **分流规则未命中 AI 域名**：如果旧订阅规则没有收录最新的 `chatgpt.com` 或 `claude.ai`，可在客户端临时切换至「全局 (Global)」模式测试；若全局能打开，说明只需更新订阅规则或在自定义规则中添加 `DOMAIN-SUFFIX,chatgpt.com,Proxy`。
