## ✦ 数据分级与评测方法论（Data Classification）

为了彻底消除行业常见的“盲目吹捧”与“虚假跑分”，本站所有品牌词条与评测文章均严格执行 **五维数据状态标签（Data Status）** 制度：

1. **本站实测（`measured`）**：附带明确测试时间戳（如 `2026-08-19 20:23 CST`、`2026-08-11 CST`）、测试拓扑环境（如电信 / 联通 / 移动三网或 9Gbps 测试带宽）与原始全节点测速 / 解锁截图。测速结果仅代表当次网络环境下的客观表现，不等于永久在线率。
2. **品牌资料（`vendor`）**：来自品牌方官方公告、面板说明或推广资料（例如“晚高峰零丢包”、“1 小时故障修复承诺”、“不限设备连接”等）。本站统一添加 **「品牌资料显示」** 前缀，供用户参考并在实测中交叉核验。
3. **商务参数（`commercial`）**：套餐计费方式、月均折算单价、流量额度、优惠码与折扣规则。由于各家机场套餐可能随活动动态调整，下单前请以目标官网实时显示为准。
4. **编辑分析（`editorial`）**：基于线路架构（IEPL 内网专线 / IPLC 专线 / BGP 中转）、协议特性（VLESS / Trojan / Hysteria 2 / Shadowsocks）与同源站群关系给出的选型建议与风险提示。
5. **历史归档（`historical`）**：曾在本站早期项目库留存记录、但当前缺乏近期实测或独立入口待核实的 14 家历史品牌档案，统一排在品牌库末尾并标注 `待核实`，绝不混充当期主推数据。
